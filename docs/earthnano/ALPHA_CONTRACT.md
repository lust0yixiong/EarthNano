## 功能来源说明

OpenScience 的 Python/R、Compute、文件/二进制产物、版本及 Reviewer，Harness² 的递归、匿名选择、完整 sweep/过滤/并发/续跑、Library/reflection 和同域后续任务经验，均为固定上游已有能力。把这些能力接到同一执行、配置隔离、预算/停止和证据生命周期属于本项目的融合工作，不能仅因需要新增接口就称为需求扩散。

平台级配置批准/发布/回滚、失败证据自动触发优化、完整精确 API/美元/耗时账本，属于 EarthNano 新增产品机制，见下方独立清单。本轮不展开，不因其未实现就判定上游融合缺失。逐模块源码依据见 [功能来源与范围](FUNCTION_ORIGINS.md)；原 Library adoption 及经验传递仍须保留。

- 测试、manifest 或 verifier 的覆盖范围必须匹配要求。固定输入关联不等同文件访问证明；语义分数不等同科研正确性；eligible 不等同已发布。
- 原项目已有可选、平台或环境测试跳过必须单独说明，不能记成通过；新增失败须对照原项目定位。
- PR、工作树和运行进程以实时状态为准；上一轮成功不自动证明本次修改后成功。
- 原始密钥不进入仓库、日志、包或证据。付费验证有明确上限，记录所有失败尝试；不能挑选高分重跑来证明收益。
- GitHub Actions 仅在独立渠道和旧上游自动任务安全隔离后启用。新代码经 PR 审查；最终发布产物必须对应已验证提交。
