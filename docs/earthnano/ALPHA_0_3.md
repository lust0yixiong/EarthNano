# OneEarth 0.3-Alpha 变更项

本文件记录 0.3-Alpha 的改动项，不表示 0.3 已发布；当前安装包和版本号仍为 0.2.0-alpha.1。

## 修复：连续发送时旧轮执行占用未恢复（2026-10-30）

0.2-Alpha 用户反馈：在 macOS、Claude Code 后端正常发送下一条消息时，出现
`Session execution remains owned pending original result and resource settlement`，重开分支后恢复。
现有日志未保留该次异常的完整执行证据；本轮修复的是已通过回归复现的同类恢复缺口。

原执行的结果读取暂时失败，或读取时终态/租约释放尚未落盘，会令统一执行记录保留
`cleanup: unknown`。此前即使原始记录随后已经确认收尾，后续 Send 仍只检查旧状态，
不再核对原始所有者，因此同一会话会持续被拦截。

- 后续 Send 先核对已结束的旧执行，复用原 `SessionExecutionHost.readResult` 和
  `ExecutionCore.reconcileOriginal`；不重发旧提示词，不生成新预算或替换旧执行标识。
- 只有原驱动完全结束、原始持久化终态和资源释放均确认时才解除占用。核对仍需匹配
  原提示词的运行时准入标识，不能借用同一提示词被 Resume/重试后的新执行结果。
- 运行中、资源未释放、身份缺失/被替换及超时中断继续阻止重入；中断仍走原重启/Resume
  恢复路径。原始模型调用或任务所有者失败不会被较晚的成功记录改写为成功。
- 核对成功后释放旧执行的容量和文件所有权，不退还已消耗预算；并行核对共用同一承诺，
  避免重复收尾。普通 Send 与优化运行仍通过同一执行核心。

验证覆盖终态晚落盘、租约晚释放、暂时证据读取失败后原会话连续发送，以及运行中拒绝、
超时隔离、准入标识不匹配和原始失败保留。最初两个恢复回归在修复前均因同一占用错误失败。

- 8 个测试文件共 463 项通过、0 失败；1 项可选付费 DeepSeek 测试未启用，按原配置跳过。
- 通过原 Claude Code 框架与本地模拟模型服务验证普通 Send、取消、中断恢复及原始
  Session JSON 所有权保护；测试不访问在线模型。沙箱禁止本地 socket，完整回归在隔离
  目录、具备本地 socket 权限的环境执行，未修改验证规则。
- 验证复用已安装 0.2-Alpha 的真实原生进程所有权模块，未修改共享依赖或已安装应用。
- main 类型检查、改动文件 ESLint / Prettier 和 `git diff --check` 通过。

当前未打包、未安装或合并，真实客户端连续使用仍需版本验收。

## OneEarth 品牌整合

应用显示名称由 EarthNano 改为 OneEarth，启动页复用用户提供 SVG 的原始字形，保留细体 ONE、粗体 EARTH 与 R 的红色竖笔，搭配已确认的蓝绿涡流图标。横向组合用于品牌展示；启动时沿用涡流聚合，上方图形归位后与下方字标共同呈现。

桌面/网页标题、系统显示、安装包名称和 DMG 提示同步更名。GitHub 仓库地址、旧版下载链接、应用 ID、协议和已保存的用户数据路径保留原兼容身份。发布校验同时识别 OneEarth 和历史 EarthNano 文件名；CI 从 `package.json` 读取产品名。

字标及横向组合由 `scripts/oneearth-brand.mjs` 导出，图标本体仍由既有导出流程管理。

## 启动呈现与图标

- 采用已预览选定的「涡流聚合」：蓝绿粒子汇成涡流标志，品牌名称随之出现，约 3.2 秒后保持静态。加载完成可随时进入应用，不强制等待动画。
- 聚合轨迹对应新版图标：围绕主体圆心沿圆形轨迹收拢，外侧略晚归位；所有粒子归位后才渐显完整图标。完整图标不再额外旋转或缩放，保证粒子与旋叶在交接时重合。
- 运行时检查、数据库启动、会话加载等现有入口继续共用同一个加载组件；跨入口重挂载延续同一时间线。支持减少动态效果、30 fps 上限、2× DPR 上限、隐藏窗口暂停、卸载清理及无 Canvas 静态回退。
- 图标采用用户于 2026-10-23 暂定的 v27 蓝绿渐变版。保留已确认的正圆主体、右侧圆润尾端、自然留白和外散粒子。`build/earthnano-logo.svg` 是统一矢量源，应用内标志、启动粒子、系统图标和托盘均由它导出。
- 应用内标志保持透明，系统应用图标沿用现有白底外框与平台尺寸。移除旧图专用描边遮罩，避免误套旧轮廓。导出命令与资源清单见 [APP_ICON.md](APP_ICON.md)。

本项不修改科研任务、Notebook、Harness² 执行/优化机制，不包含新模型验证、发布安装包或替换本机应用。
